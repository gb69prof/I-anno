# Mappa dei contenuti

Tesoro di Atreo → architettura → paesaggio delle tholoi → storia delle esplorazioni → Pausania e nomenclature moderne.

## Asse storico

Lineare B → wanax → regni palaziali → memoria culturale → impossibilità dell’identificazione individuale.

Iliade → Odissea → Pindaro → Orestea → Sofocle → Euripide → mitografi e ricezione.

## Connettore principale

porta monumentale → soglia → ritorno del re → ingresso nella reggia → morte. È una pista critica, non una sequenza storica ricostruita.
